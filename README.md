# ha-info-digest

Дополнение Home Assistant, которое собирает сообщения из городских чатов (Telegram, Max), размечает их по категориям, группирует в события и отдаёт Алисе короткие сводки и голосовые оповещения через Яндекс.Станции.

Статус: в разработке.

## Как это работает

1. Сборщик читает новые сообщения из подключённых групп и сохраняет их в локальную базу.
2. Языковая модель размечает сообщения по категориям редактируемого классификатора и объединяет их в события.
3. Сводки и ответы по категориям публикуются в сенсоры Home Assistant.
4. Алиса отвечает на вопросы через интеграцию Yandex.Station Intents и озвучивает оповещения по правилам.
5. Настройки (источники, категории, правила, Станции) меняются через Telegram-бота управления.

## Безопасность

В репозитории нет ключей, токенов, сессий и данных. Все секреты хранятся в настройках дополнения внутри Home Assistant, база сообщений — в томе дополнения.
